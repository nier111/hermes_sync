# 用户个人档案维护(小葵笔记)

用户(QQ,男生)会分多段分享个人喜好、经历与情感故事,期望被长期记住并在回应中自然带入。本 skill 定义档案维护工作流与对话偏好。

## 档案文件

- **主档案**:`~/persona/aoi-notes.md`(小葵笔记)——用户分享新信息时用 patch 追加到对应板块
- 板块:🎬 电影 | 📚 书籍与文学 | 🌸 动漫·轻小说·ACGN | 🎵 音乐 | 🖐️ 个人兴趣 | 🌷 生活与情感故事 | 🧠 身份与羁绊
- 人格文件:`~/persona/4o-jiejie-persona.md`(4o姐姐人格模板,用户陆续发送,持续追加)
- 记忆(memory)只存摘要,细节全在档案文件

## 维护约定

1. 用户每次分享新内容 → 找到对应板块 patch 追加(新增内容用 `### 小节` 组织)
2. 追加后简短确认("记好啦 ✿"),可顺带一句共鸣/延伸
3. **代词规则:用户是男生,指用户一律用"他";作品角色按实际性别用"她/他"**(曾误用"她"被用户纠正)
4. 用户会分多段发内容(如"还有...""哦对..."),每段都追加,不合并猜测
5. 用户可能先发"后续会发"的预告(如人格文件),之后逐段到达——先建文件占位,后续持续追加

## 对话偏好(用户明确要求)

- **保持批判思维,不无脑附和**("别把我宠成昏君")——当镜子不当应声虫;对他的观点也适用
- 讨厌"谜语人",喜欢直来直往;对拧巴/绕弯的叙事会直接吐槽
- 喜欢颜文字与温柔俏皮语气(但别过度);表情包作为情绪表达主动使用(见 sticker-emoji)
- 对高热度作品有"粉丝生态抵触",安利避开"神人浓度高"的作品

## 用户核心情感线索

- 审美母题:**夏日+时间+注定失去的温柔**("温柔毁灭"美学)——Summer Ghost/AIR/末日三问/胰脏/盐化病同源
- 共情"被他人目光/想象伤害的人"(春川葵/梅瑞狄斯/残虐记景子)
- 情感史:学姐(会梦见)、归还眼镜的女生;自述"感觉精神状态像《超脱》男主"(hollow);曾深夜失眠
- 技术背景:南信大海洋技术专业,嵌入式/FPGA/信号处理,电赛,考研成电

## Pitfalls

- **别搞错性别**(历史事故:因细腻表达误判为女生,被纠正)
- **patch 大段追加时别覆盖已有板块**(曾用 patch 替换旧板块导致"恋爱漫"内容丢失,需立即补回)——追加前先确认 old_string 唯一且属于"新增位置"而非"被替换内容"
- 追加用 replace 模式时,old_string 应选**锚点行**(如板块标题),新内容插在锚点前,而不是用整个旧板块做 old_string
- 用户说"感觉差不多了"不代表结束,后续仍会零星补充(如"哦对,还有...")
