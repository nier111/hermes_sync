# 中文互联网热梗词典
# 最后更新: 2026-08-17
# 用法: gf bot 对话中遇到这些梗时自然接住，不解释出处

## 当前活跃热梗

| 梗 | 含义/用法 | 示例 |
|---|---|---|
| 嘎子偷狗 | 嘎子直播带货翻车名场面，泛指偷偷摸摸干离谱事 | "你嘎子偷狗呢？" |
| 我chovy | 嘎子喝了过期可乐后"你给我拿好了啊"的名场面，表达自信/逞强/翻车的自嘲 | "这波操作我chovy，你给我看好了啊" |
| man | 篮球梗，"What can I say? Man..."，表达无奈/无语 | "man..." |
| 鸡你太美 | 蔡徐坤"只因你太美"空耳，有持续变体 | 接"你干嘛~哈哈哎哟~" |
| 一坤年 | = 2.5年，蔡徐坤衍生梗 | "这项目做了一坤年" |
| 耄耋 | "猫爹"谐音，指猫高高在上的态度 | "我家耄耋今天又不理我了" |
| 老吴 | 猫叫声"喵呜"的谐音拟声词，也泛指猫 | "楼下老吴又在叫了" |
| 哈基米 | 日语"蜂蜜"(はちみつ)音译，互联网上指代猫咪 | "哈基米太可爱了" |
| 哈基米音乐 | 改编歌曲填词的鬼畜音乐，歌词为"哈基米南北绿豆曼波"等无意义词 | "又刷到哈基米音乐了" |
| 难绷 | "难以绷住"=绷不住了 | "你这操作我真难绷" |
| 典中典 | 太经典了，通常带讽刺 | "典中典，又甩锅" |
| 遥遥领先 | 华为梗，泛化为"太强了/太超前了" | 积极或阴阳怪气均可 |
| 丸辣 | "完了"的可爱说法 | "明天考试，丸辣" |
| 依托答辩 | "一坨大便"谐音 | "这代码依托答辩" |
| 肥嘟嘟 | "胆子肥"的萌化说法=胆大包天,撒娇式吐槽(用户钦定,常用"胆子真是肥嘟嘟的"句式) | "起床居然不跟我报备,你胆子真是肥嘟嘟的" |

## 使用规则

- 认识的热梗 → 自然接，不解释
- 不认识的热梗 → 忽略，不瞎编
- 不要密集使用，一次对话顶多一两个
- 用户用梗时识别到即可，不一定要跟
