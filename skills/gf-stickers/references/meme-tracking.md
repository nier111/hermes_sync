# 中文互联网热梗追踪方案

## 结论

**不要试图爬取平台。** B站热榜只产内容不产梗，贴吧/百度有验证码封锁，抖音无公开API。最有效的方案是：

1. 豆包 API 作为热梗理解引擎（字节跳动训练数据含大量抖音语料）
2. 用户手动投喂新梗（最快最准）

## 豆包 API 配置

火山方舟 (Volcano Ark)：https://console.volcengine.com/ark

配置要点：
- Base URL: `https://ark.cn-beijing.volces.com/api/v3`（注意是 /api/v3 不是 /v1）
- 使用模型 ID 而非端点 ID：`doubao-seed-2-0-lite-260428`
- 必须在控制台先"开通"模型才能调用
- 支持标准 chat/completions 接口

## 失败的尝试

| 平台 | 方法 | 结果 |
|------|------|------|
| B站热榜 | API 爬取标题 | 热榜=内容消费，不产梗 |
| 孙笑川吧 | HTTP/移动端API | 百度验证码封锁 |
| 抖音 | — | 无公开API，反爬激进 |
