# 中文互联网热梗追踪方案（2026-08-12 更新）

## 已验证可用的方法

### B站浏览器搜索（推荐）

浏览器访问 `https://search.bilibili.com/all?keyword=热梗&order=click`

- 不需要 API key，浏览器工具自带反检测
- 热梗合集视频标题直接列出梗名
- 可点进视频读评论区热评提取新梗
- **curl/shell 调用 API 连续请求会触发 412 反爬**

### 用户投喂（最准）

用户刷到新梗直接告知，当场写入词典。准确率 100%。

## 豆包 API 的实际能力

已配置模型 `doubao-seed-2-0-lite-260428`（火山方舟）。

**三档模型实测结论**：lite/pro/turbo 对口头传播谐音梗（"我chovy""老吴""耄耋"）均编造假来源，且三个模型编出三种不同的假答案。

- 适合：润色用户已确认梗的释义和例句
- 不适合：自主发现新梗、未经用户审核写入词典
- 联网搜索：当前 lite 模型不支持

## 失败的尝试

| 平台 | 方法 | 结果 |
|------|------|------|
| B站热榜 API | curl 抓取标题 | 热榜内容不产梗 |
| B站搜索 API | curl 搜索"热梗" | 两次请求后触发 412 |
| 孙笑川吧 | HTTP/移动端 API | 百度验证码封锁 |
| 抖音 | — | 无公开 API |
| 豆包 API 自主发现 | lite/pro/turbo | 全部编造假梗 |
