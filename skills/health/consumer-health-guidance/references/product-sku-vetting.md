# 商品 SKU 核对流程（保健品/健康产品）

用户会照推荐下单，也会自己顺手搜同品牌的其他规格。推荐的失败模式不是"品牌选错"，
而是"品牌对、规格错"。以下流程专治这一类。

## 1. 下单前四项核对（写给用户的原话模板）

```text
1. 商品名明确写出剂量（例：500 mcg / 1 mg）
2. Supplement Facts 里有效成分只有目标那一种
3. 不含 5-HTP / GABA / 缬草 / 色氨酸等复方
4. 渠道：品牌官网 / iHerb 自营 / 京东国际自营 / 品牌官方旗舰店
```

## 2. 交给用户的可核验指纹

只说"买这个牌子"是不够的。至少要给出其中两样，让用户能在商品页上对得上：

- 品牌 + 完整商品名（含剂量与粒数）
- Item #（Life Extension、Nature's Way 等有，Natrol 部分有）
- UPC 条形码（最稳，商品页常写 UPC 或 737870 开头的货号）
- 品牌官网产品页 URL

对照示例（褪黑素）：

```text
认可：Life Extension Melatonin, 1 mg, 60 capsules
      Item #00329 / UPC 737870329060
拒绝：Life Extension Melatonin IR/XR 1.5 mg（缓释，规格不同）
```

## 3. 易混的套娃类型（跨品牌通用）

| 套娃类型 | 识别特征 | 处理 |
|---|---|---|
| 成人款 vs 儿童款 | 包装写 `Kids` / `Ages 4+` / 软糖口味款 | 明确说"别买带 Kids 的" |
| 普通释放 vs 缓释 | `Time Release` / `6 Hour` / `XR` / `IR/XR` | 按需求选，别混用 |
| 单方 vs 复方 | Supplement Facts 里多于一个有效成分 | 调作息/起始剂量场景只买单方 |
| 剂量套娃 | 同系列 300 mcg / 1 mg / 3 mg / 5 mg / 10 mg | 先定剂量区间，再选 SKU |
| 规格套娃 | 同一剂量 60 粒 / 100 粒 / 200 粒 | 粒数不影响效果，只影响单价 |
| 地区/库存换装 | 同一 UPC 在不同站点包装不同 | 认 Item#/UPC，不认封面图 |

## 4. 商品链接的处理原则

- iHerb / 品牌官网的长链接可以直接给，但提醒"以品牌官网 Item#/UPC 为准"。
- 淘宝/京东商品 ID 与店铺授权会变化，给**搜索关键词**更稳：

```text
普丽普莱 褪黑素 1mg 官方海外旗舰店
Natrol 褪黑素 1mg 官方
```

- 搜索结果里的推广位（bing/百度 aclick 跳转、sponsored 条）、代购店、闲鱼 → 不作为推荐来源。
- 用户已看到某个价格时：不要凭价格判断真假，先收链接核对规格与渠道。

## 5. 自洽性检查（本会话踩过的坑）

有一次回复正文写"0.5 mg，100 粒"，链接却指向 200 粒装；虽然随后自我纠正，但用户
已经看到前后不一致。发出去之前逐项对照：

```text
正文里的 剂量 = 链接 SKU 的 剂量?
正文里的 粒数 = 链接 SKU 的 粒数?
正文里的 剂型 = 链接 SKU 的 剂型（普通/缓释/软糖）?
正文里的 Item#/UPC = 链接 SKU?
```

## 6. 用户当场纠正时的回应方式

本用户会主动核对（例如指出"1 mg 那个好像是儿童褪黑素"）。此时：

1. 先肯定这个发现，不辩解（"你看得没错"）。
2. 立刻重新检索，核对该 SKU 的适用人群与产品线。
3. 如果确实容易混，**换一个不易混的推荐**，而不是让他继续和套娃包装斗智斗勇。
4. 给出"如何自己识别"的判断方法（看包装关键词、看商品页适用人群）。
